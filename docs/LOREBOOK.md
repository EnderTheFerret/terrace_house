# Terrace House, Tel Aviv and Israel World Info

`content/lorebook.json` is a native SillyTavern World Info JSON book with 24 entries, also read directly by Shared Roof's scene prompt builder. It covers the show format, ordinary house life, Tel Aviv neighborhoods and markets, travel, language, money, Shabbat, kashrut and holidays. It contains no real cast impersonations or private character biographies.

In SillyTavern, open **World Info**, import this JSON file, and attach the book to the relevant character or chat. Use scan depth **4**, an absolute budget around **550 tokens**, and recursive scanning **off**. One setting/knowledge-boundary entry is constant; the others activate on their keywords. Entries explicitly prevent recursion, use whole-word matching, and have deterministic activation. These follow the [official World Info documentation](https://docs.sillytavern.app/usage/core-concepts/worldinfo/) and the [native entry definition](https://github.com/SillyTavern/SillyTavern/blob/release/public/scripts/world-info.js). Actual import in a running SillyTavern installation was not exercised here.

The game supports this book's constant and keyword entries, disable flag, priority, and whole-word matching. It scans the scene premise, recent spoken text and latest typed words, rather than hidden character cards. Selection never scans entry content recursively and uses at most **2,200 characters**, approximately 550 tokens. Lore is optional under the overall prompt budget: personal memories and the current conversation take precedence. Existing fictional game-location descriptions remain available alongside it. This loader is a small adapter for this book, not a complete SillyTavern implementation.

Every entry has source identifiers in `extensions.sources`; the book's top-level extensions resolve them to URLs or the local README. Those citations are metadata and do not appear in spoken prompts. Factual reference and original game direction are labeled separately. Source checks were made on October 6, 2026. Historical municipal tour descriptions support neighborhood context only, not current businesses, prices or timetables.

The sources include [Netflix's series announcement](https://about.netflix.com/en/news/netflix-starts-production-on-new-series-of-terrace-house-in-karuizawa-japan), [Fuji Television's format description](https://www.fujitv.com/variety/terrace-house/), [UNESCO's White City entry](https://whc.unesco.org/en/list/1096/), [Tel Aviv's neighborhood guide](https://www.tel-aviv.gov.il/en/WorkAndStudy/Pages/Enjoying-City-Life.aspx), [municipal tour descriptions](https://www.tel-aviv.gov.il/en/WorkAndStudy/Documents/the%20tel%20aviv%20experience.pdf), [official Shabbat guidance](https://visit.tel-aviv.gov.il/Pages/Shabbat.aspx), [official transit guidance](https://visit.tel-aviv.gov.il/move/in-tel-aviv), [Bank of Israel currency information](https://www.boi.org.il/en/economic-roles/banknotes-and-coins/), and Chabad's [kashrut](https://www.chabad.org/library/article_cdo/aid/113425/jewish/What-Is-Kosher.htm) and [holiday](https://www.chabad.org/holidays/default_cdo/jewish/holidays.htm) references. Religious practice references describe traditions, not assumptions about every Israeli or resident.

The game calendar, weather, venue rules, character habits and learned facts remain authoritative. Knowing a hometown or a relative's name is not proof that two characters have met. Lore provides public context; it cannot establish a new personal connection.
